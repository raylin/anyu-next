# Persona / Insight Consent v0

## 1. 未來可能的個人化洞察

未來 ANYU 可能發展更長期的個人化功能，例如 Persona、Personal Insight Graph，或其他依據你多次分析結果整理出的互動輪廓。

## 2. v0 階段預設

在 v0 階段，我們不應預設將你的多次分析結果建立成長期個人化檔案。

不同意長期洞察，也不應影響你使用單次分析功能。

## 3. 明確同意才保存長期洞察

如果未來要把你的多次分析結果去識別化後整合成個人化洞察，我們應在功能啟用前取得你明確同意，而不是默默預設打開。

建議方向是 opt-in，而不是預設收集。

## 4. 使用者可以刪除或停止

如果未來上線此類功能，使用者應可以：

- 關閉個人化洞察
- 要求刪除既有的長期洞察資料
- 在不參與長期洞察的情況下，繼續使用單次分析功能

## 5. 建議 UI 文案

### 同意版本

我同意 ANYU 將我的分析結果去識別化後，用於建立未來的個人化洞察，讓後續測驗更貼近我的互動模式。

### 不同意版本

不同意也可以使用本次分析；我們不會因此影響你的結果。
