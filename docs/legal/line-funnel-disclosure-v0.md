# LINE Funnel Disclosure v0

> 這份文件是 v0 內測階段的基礎草稿，描述的是預計採用的通知與交付方向，不代表 LINE API 或完整自動化流程已經全部上線。

## 1. 為什麼使用 LINE

對台灣使用者來說，LINE 是更自然、固定成本也相對可控的後續通知與留存管道。因此在 v0 階段，LINE 會是優先考慮的完整分析交付與內測通知方式。

## 2. 加入 LINE 後我們可能取得什麼

如果未來你加入 ANYU 的 LINE 官方帳號，或透過 LINE 留下聯絡方式，我們可能取得：

- 你主動提供的 LINE ID 或帳號互動資訊
- 你是否有收到通知或點開訊息的基本互動訊號
- 你主動回覆給我們的內容

## 3. 我們會怎麼使用 LINE

我們可能將 LINE 用於：

- 傳送完整分析
- 傳送內測通知
- 傳送新測驗或新模組通知
- 回覆你的問題或刪除請求

## 4. 我們不會怎麼使用 LINE

我們不打算把 LINE 當成高頻推播工具，也不會把你的 LINE 資料出售給第三方。

在未來正式流程上線前，我們也不會把「加入 LINE」包裝成你唯一能使用產品的必要條件。

## 5. Email 作為備用選項

Email 可以作為備用聯絡方式。若你不想使用 LINE，原則上仍可留下 Email 以取得後續內容或通知。

## 6. 取消與刪除

如果未來你加入 LINE 官方帳號，你可以隨時封鎖、取消追蹤，或透過我們提供的正式聯絡方式要求刪除資料。

正式公開前，需要補上明確的刪除請求窗口與作業流程。
