# Handoff: C-stage Frontend Stack Selection Prep

Date: 2026-05-18

Project: Opportunity Radar / 暗語 ANYU

## Objective

Create a requirements and evaluation document for formal C-stage frontend stack selection, without choosing the final stack yet.

## Scope

- consolidate product, design, runtime, experiment, privacy, and launch-cycle requirements
- define what C-stage must decide and what it should not decide yet
- compare candidate stack options and produce a recommended shortlist
- document migration implications from the current prototype

## Constraints

- documentation only
- no prototype behavior changes
- no runtime, prompt, or schema changes
- no Dcard script changes
- no new stack implementation
