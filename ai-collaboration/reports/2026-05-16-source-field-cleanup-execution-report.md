## Behavior Changed

The extractor now:

1. derives `source_id` from `raw_path.stem`
2. includes `source_id` in prompt metadata
3. sends only the raw filename, not the absolute path, in prompt metadata
4. enforces `signal["source"] = source_id` after model output and before schema validation/save

Examples:

```text
outputs/raw/sample_001.txt -> sample_001
outputs/raw/dcard_case_003.md -> dcard_case_003
/tmp/test_input.txt -> test_input
```

A minimal prompt clarification was added so the model is instructed to use `source_id` and avoid absolute paths. The final code enforcement ensures cleanup even if the model ignores that instruction.
