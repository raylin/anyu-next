// PAYMENT SHELL + MODULE ACCENT · UX/UI 探索

一套固定的 ANYU 付款殼，外加可換的模組調性

問題：Module 01 的輸入／結果頁是 Riso editorial，但 checkout、ReturnURL、等待、狀態頁偏淡雅 generic，體驗在付款前後斷裂。 解法：把付款流程拆成 固定 shell（版面、卡片、按鈕、進度、狀態元件、藍新信任聲明、support / 退款）＋ module accent（標題、hook、motif、少量顏色、狀態比喻）。 未來 Module 02「職場暗流雷達」只換 accent token 與 motif，不重做整套付款 UX。 三個方向：A 保守 · B 中間 · C 可延展（推薦）。

Shell 共用 — 跨模組固定不動 Module 01 accent — 可換的調性層 藍新（NewebPay）第三方頁面不在此次設計範圍，但前後的 ANYU 頁面要連續。
