# AI Collaboration Artifacts

This directory is the canonical execution-memory area for repo work.

## Structure

- `handoffs/`: user-provided or execution-start task briefs
- `reports/`: task execution reports
- `research/`: review bundles, QA notes, synthesis docs, and planning artifacts
- `decisions/`: explicit approved decision records
- `templates/`: canonical workflow templates
- `summaries/summary_log.md`: canonical persistent summary log
- `inbox/`: intentionally untracked working area for temporary inputs

## Active Vs Historical

- `templates/`, `decisions/`, and `summaries/summary_log.md` are active operating references
- most `handoffs/`, `reports/`, and `research/` files are historical evidence and should not be deleted casually
- preserve history unless a later cleanup handoff explicitly approves archival or removal

## Cleanup Rule

- do not delete historical artifacts just because they are old
- prefer adding indexes and boundary docs before deletion
- keep raw private inputs out of committed collaboration artifacts
