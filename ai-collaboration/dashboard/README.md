# ANYU Project Dashboard

Static owner-facing dashboard:

- `anyu-project-dashboard.html`

Open the HTML file locally in a browser. It has no build step, no external network dependency, and no runtime behavior.

Update cadence:

- after every 3-5 major handoffs
- after any launch gate change
- before and after production payment enablement
- whenever a critical blocker changes state

Do not add secrets, raw payment payloads, tokenized URLs, private billing/proof documents, or customer/user input to this dashboard.
