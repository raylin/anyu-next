QA Tooling

Sandbox helper: corepack pnpm run qa:newebpay:sandbox -- create-checkout creates a fresh staging sandbox checkout and writes the provider form outside the repo under /private/tmp/anyu-newebpay-smoke/.

Env preflight: corepack pnpm run qa:env:preflight -- fake_paid_queue and related modes check local QA readiness by env name presence only before running staging smoke commands.

Local env autoload: QA scripts load apps/web/.env.local when shell env is absent. Exported shell env wins over local file values; values are never printed.

Verification: poll-status and verify-after-payment read local state from the temporary directory and print only sanitized status categories and booleans.

Safety: helper and preflight output must not include provider secrets, TradeInfo, TradeSha, raw pcs_/pa_ tokens, tokenized URLs, raw input, card data, env values, lengths, prefixes, suffixes, hashes, or checksums.
